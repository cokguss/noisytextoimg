Kebijakan Privasi

Noisy Text To IMG dirancang seringan mungkin: kamu menulis prompt, gambar dirender, tidak ada akun dan tidak ada database kami yang menyimpan isi prompt-mu.

Ringkasan singkat

Tidak kami simpan: prompt, negative prompt, dan file gambar hasil generate tidak disimpan di server kami sebagai riwayat akun.

  • Tidak perlu registrasi; kami tidak punya profil pengguna.
  • Prompt hanya dikirim saat kamu menekan Buat Gambar, lalu diteruskan ke layanan render untuk task tersebut.
  • Hasil berupa URL gambar sementara dari penyedia render; kami tidak membuat arsip galeri pribadi.

Data yang diproses

Saat kamu generate, request berisi minimal:

Jenis Contoh Tujuan
prompt Teks deskripsi gambar Merender gambar yang kamu minta
negative prompt Opsional, hal yang dihindari Menyempurnakan hasil render
pengaturan Model, CFG Scale Parameter teknis generate
teknis Task ID, status antrean Polling status & debugging error

Kami tidak meminta nama, email, nomor telepon, atau pembayaran di aplikasi ini.

Prompt & hasil gambar

Prompt diteruskan ke penyedia API render (live3d) untuk memproses task generate. Setelah task selesai, gambar diambil lewat URL hasil (biasanya temp.live3d.io).

  • Kami tidak menjual, menyewakan, atau memasarkan isi prompt-mu.
  • Kami tidak menampilkan prompt orang lain. Tidak ada feed publik di aplikasi ini.
  • URL gambar bersifat sementara mengikuti kebijakan penyedia; unduh ke perangkatmu bila ingin menyimpan permanen.
  • Jangan masukkan data pribadi (NIK, alamat, nomor identitas, dsb.) ke dalam prompt.

Layanan pihak ketiga

Render API

Memproses prompt → gambar. Memiliki log operasional sendiri sesuai kebijakan mereka.

Font & ikon lokal

Space Grotesk, JetBrains Mono, dan Phosphor di-host sendiri di situs ini. Tidak ada request ke CDN font pihak ketiga.

Contoh gambar

Kartu contoh memakai picsum.photos (placeholder). Hanya dimuat sebagai inspirasi UI.

Tautan keluar dibuka dengan rel="noopener". Kebijakan pihak ketiga di luar kendali kami.

Cookie & penyimpanan lokal

Studi ini tidak memakai cookie tracking (tanpa analytics iklan, tanpa pixel retargeting, tanpa akun sesi).

  • Pengaturan UI di browser-mu (mis. prefers color scheme) mengikuti preferensi sistem.
  • Server hanya memproses request generate; tidak menetapkan cookie identifikasi pengguna di aplikasi kami.
  • Riwayat generate (prompt + URL hasil, maks 24) disimpan di localStorage browser-mu sendiri, tidak dikirim ke server. Hapus kapan saja dari bagian Riwayat atau via pengaturan browser.
  • Cache aset statis (CSS/JS) mungkin disimpan browser demi kecepatan. Itu standar HTTP, bukan pelacakan.

Keamanan

  • Komunikasi browser ↔ server lokal memakai origin yang sama di pengembangan.
  • Request ke penyedia render memakai header teknis yang diperlukan endpoint tersebut.
  • Tidak ada penyimpanan hasil di disk server aplikasi sebagai “galeri” pengguna.
  • Tidak ada kata sandi untuk disimpan, karena memang tidak ada sistem login.

Tidak ada sistem yang 100% bebas risiko. Jangan kirim materi rahasia lewat prompt.

Hak kamu

  • Kamu mengontrol apa yang diketik di prompt. Itu satu-satunya “data input utama”.
  • Kamu bisa mengosongkan field kapan saja sebelum generate.
  • Kamu bisa menghapus file hasil unduhan dari perangkatmu sendiri.
  • Karena tidak ada akun, tidak ada data profil yang bisa kami “hapus dari database”. Memang tidak ada.

Anak di bawah umur

Layanan ini ditujukan untuk audiens umum. Jika kamu di bawah usia sesuai hukum yurisdiksimu (mis. < 13-18 tahun tergantung wilayah), gunakan hanya dengan izin wali. Orang tua/wali yang mengkhawatirkan penggunaan anak dapat memantau penggunaan browser.

Perubahan kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Tanggal “terakhir diperbarui” di atas menunjukkan versi terkini. Perubahan material (mis. penambahan penyimpanan riwayat) akan diusahakan ditandai jelas di halaman ini.

Kontak

Pertanyaan soal privasi? Hubungi tim Noisy melalui kanal resmi proyek. Sertakan deskripsi singkat request (tanpa mengirim ulang prompt sensitif bila tidak perlu).
