Mulai dalam hitungan detik, tanpa akun dan tanpa install.

Tulis prompt

Deskripsikan gambar di panel kiri. Semakin detail subjek, cahaya, dan gaya, semakin bagus hasilnya.

Atur model & CFG

Pilih model (fotorealisme / anime) dan geser CFG Scale. CFG 5-8 umumnya seimbang antara kreativitas dan kepatuhan prompt.

Apa itu Noisy Text To IMG?
Studio text-to-image di browser. Kamu menulis deskripsi, kami merender gambar lewat model diffusion. Tidak perlu akun atau GPU lokal.
Bagaimana cara menghasilkan gambar terbaik?
Tulis prompt spesifik: subjek, pencahayaan, lensa/sudut, gaya (mis. cinematic, editorial, 35mm film). Gunakan prompt negatif untuk menyingkirkan artefak (blur, watermark, bad anatomy). Coba beberapa model bila hasil kurang cocok.
Model mana yang sebaiknya dipilih?
AbsoluteReality v1.8: fotorealisme detail tinggi (default).
majicmix Realistic v7: potret manusia alami.
MeinaMix v11: gaya anime / ilustrasi.
Apa itu CFG Scale?
CFG mengontrol seberapa ketat model mengikuti prompt. Rendah (1-4) lebih bebas/artistik; tinggi (12-20) lebih literal tapi bisa berlebihan. Rentang nyaman untuk sebagian besar kasus: 5-9.
Berapa lama proses generate?
Umumnya sekitar 15-60 detik tergantung antrean server. Progress bar menampilkan status render; kalau timeout, tekan Coba lagi.
Apakah gambar & prompt saya disimpan?
Tidak ada database kami yang menyimpan prompt atau hasil. Prompt hanya dikirim saat kamu menekan generate. Detail lengkap di Kebijakan Privasi.
Di mana riwayat generate saya disimpan?
Hanya di browser-mu sendiri (localStorage), maksimal 24 terakhir — tidak pernah dikirim ke server kami. Hapus per item atau semuanya dari bagian Riwayat, atau bersihkan data situs di pengaturan browser.
